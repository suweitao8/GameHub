# GameHub vs Bilibili 游戏区需求对比报告

> 日期：2026-07-22

## 二、高优先级需求（本轮可实现）

### 1. 🟡 游戏详情页「稍后再玩」功能

**需求描述**：
用户可以将感兴趣的游戏加入「稍后再玩」列表，方便后续快速找到。

**B站参考**：
B站视频有「稍后再看」功能，用户可以在任意视频页点击加入稍后再看列表。

**实现方案**：
- 新增 `watchLater` signal 状态
- 使用 `localStorage` 存储（离线可用）
- 在详情页 action 按钮区新增「稍后再玩」按钮
- 用户头像下拉菜单中增加「稍后再玩」入口

**涉及文件**：
- `game-play.component.ts/html` - 新增按钮
- `game-navigation.component.ts` - 新增入口

---

### 2. 🟡 首页「猜你喜欢」推荐

**需求描述**：
基于用户浏览历史，在首页推荐个性化游戏。

**B站参考**：
B站首页「猜你喜欢」模块，基于用户兴趣推荐视频。

**实现方案**：
- 前端基于 `localStorage` 记录最近浏览的分类/标签
- 首页新增「猜你喜欢」section
- 根据浏览记录匹配推荐（纯前端实现，不依赖后端）

**涉及文件**：
- `games-home.component.ts/html` - 新增推荐 section

---

### 3. 🟡 作者空间「置顶作品」

**需求描述**：
创作者可以设置一个置顶作品，在作者空间首页优先展示。

**B站参考**：
B站 UP 主空间可以设置置顶视频。

**实现方案**：
- 后端 `author` API 返回 `pinnedGame` 字段
- 作者空间首页优先展示置顶作品
- 如未设置，取最新作品作为默认置顶

**涉及文件**：
- `game-author.component.ts/html` - 展示置顶作品
- `game-author.component.scss` - 置顶样式

---

### 4. 🟡 游戏详情页「相关标签云」

**需求描述**：
在详情页展示当前游戏的相关标签，点击可跳转搜索。

**B站参考**：
B站视频详情页有标签云，点击标签搜索同类视频。

**实现方案**：
- 详情页已展示 `game.tags`
- 优化标签展示样式为标签云形式
- 点击标签跳转搜索结果

**涉及文件**：
- `game-play.component.html/scss` - 标签展示

---

### 5.  排行榜「更新时间」维度

**需求描述**：
排行榜增加「最近更新」维度，展示最近有更新的热门游戏。

**B站参考**：
B站排行榜有「综合/点赞/投币/收藏/分享」等维度。

**实现方案**：
- 新增 `updated` 排序维度
- 后端已有 `updatedAt` 字段
- 前端新增筛选选项

**涉及文件**：
- `game-rankings.component.ts` - 新增筛选选项

## 四、本轮推荐实现

### 立即实现（5 项）

1. **「稍后再玩」功能** - 提升用户留存，纯前端实现
2. **首页「猜你喜欢」** - 提升首页个性化，纯前端实现
3. **作者空间置顶作品** - 提升作者曝光，简单展示优化
4. **详情页标签云** - 提升游戏关联发现，样式优化
5. **排行榜更新时间** - 丰富排行榜维度，简单配置

### 实现顺序

```
第1轮：标签云 + 置顶作品（30分钟）
第2轮：稍后再玩 + 猜你喜欢（45分钟）
第3轮：排行榜更新时间（15分钟）
```
