# GameHub 首页轮播与视觉跟进修复计划

**目标：** 对齐 B 站式首页的信息层次，修复轮播黑色遮罩、纯色信息栏、右侧第二排图片对齐和顶栏按钮尺寸不一致问题。

**范围：** 只改 GameHub 客户端首页、共享封面颜色工具和 GameHub 顶栏样式；不改推荐数据、API、数据库或路由。

## 实施步骤

1. 在 `scripts/test-game-cover.ts` 增加像素平均色和前景色选择的契约测试。
2. 在 `client/src/app/shared/game-cover.ts` 增加纯函数：从 RGBA 像素计算平均 RGB，并根据相对亮度选择深色或浅色前景。
3. 在 `featured-carousel.component.ts/html` 中监听封面加载，按当前图片提取平均色；图片提取失败时回退到封面兜底色，并把颜色和前景色传给信息栏。
4. 重写 `featured-carousel.component.scss` 的主卡结构：移除图片内黑色文案遮罩，把标题/作者/控制器放进平均色信息栏；桌面端用固定的右侧卡片信息区扣除量，让主卡底部对齐第二排图片底部；窄屏恢复自然高度。
5. 在 `header.component.scss` 统一登录和投稿 CTA 的高度、最小宽度、字体、圆角和间距；让游戏首页顶栏保持白色表面，保证蓝色字标和图标对比度。
6. 复查共享游戏卡片的角标与交互态契约；本轮保持普通卡片布局不变，仅确保推荐主卡角标在浅色封面上可读，并保留键盘 focus 与 reduced-motion 行为。
7. 运行像素工具测试、客户端轻量构建、变更文件 lint 和 GameHub 自检门禁；用内置浏览器在桌面与移动宽度检查轮播尺寸、底部对齐、按钮尺寸、黑色遮罩消失、无横向溢出及轮播按钮交互。

## 验收标准

- 轮播图片仍为 16:9，标题不再覆盖在图片中部/底部黑色遮罩上。
- 信息栏背景来自当前轮播图片的平均色；前景文字在浅色和深色图片上均保持可读。
- 桌面端主轮播底边与右侧第二排缩略图底边一致，而不是与右侧标题/作者信息底边一致。
- 登录和投稿按钮的高度、圆角和视觉重量一致，封面角标在浅色背景上清晰可见。
- 移动端不出现水平溢出，轮播滑动、圆点、左右按钮和键盘 focus 不退化。
