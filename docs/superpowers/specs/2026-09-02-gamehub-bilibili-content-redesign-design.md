# GameHub B 站启发式内容广场视觉重构

## Design Read

这是面向玩家和独立创作者的游戏发现/社区页，采用 B 站式内容广场语言：白色内容层、蓝色单一品牌强调、缩略图优先、紧凑信息密度和明确的内容层级；实现继续使用现有 Angular 组件与原生 SCSS，不引入新的 UI 框架。

## 现状审计

- 当前首页已经去掉了随机彩色，但过度依赖灰色占位块，真实数据为空时首屏像骨架屏。
- 分类导航仍是一排高对比胶囊按钮，入口之间互相竞争，不能像内容平台一样表达当前频道。
- 游戏卡片被白色边框、圆角、阴影和封面底部深色统计条切成独立小盒子，标题、作者和统计信息断裂。
- 推荐首屏虽然有“大卡 + 侧栏”结构，但大卡底部控制区较重，首屏没有形成内容平台的视觉锚点。
- 当前实现的真实运行页、登录/投稿表单和社区子页已经共享浅色令牌；本次重点重构首页发现链路，同时让共享卡片和导航语言影响全部 GameHub 页面。

## 视觉方向

### 令牌

- 画布：`#f6f7f8`；内容表面：`#ffffff`；分隔线：`#e3e5e7`。
- 品牌蓝：`#00aeec`，用于链接、选中线和图标；可读的实色行动蓝使用更深的语义 token。
- 文字：`#18191c`、`#61666d`、`#9499a0`，不再使用组件级灰色变体。
- 圆角：封面 8px、面板 12px、搜索框 10px、胶囊只用于状态/标签。
- 阴影：只用于弹层和悬停状态，普通游戏卡片不再使用浮动白盒阴影。

### 首页结构

1. 56px 白色顶栏：品牌、社区入口、居中的单层搜索框、账户快捷入口。
2. 分类导航：白色横向频道栏，文字 Tab，当前项由蓝色文字和底部 2px 指示线表达。
3. 推荐首屏：12 列布局，左侧推荐主卡占 6 列，右侧 6 个游戏卡占 6 列；主卡封面负责视觉锚点，标题和控制区保持轻量。
4. 普通分区：五列缩略图网格，卡片不再包裹白色边框；封面 16:9，标题最多两行，作者/数据在标题下方统一排列。
5. 空状态、加载态、错误态继续保留，使用同一套 surface、border 和 focus token。

### 无封面策略

真实封面始终原样显示。无封面普通卡使用浅蓝灰单色底和标题首字；推荐主卡使用单一深蓝品牌底和低对比首字，保证没有数据时首屏仍有视觉锚点，但不生成彩虹色或渐变。

## 交互与响应式

- 卡片 hover 只做封面轻微放大、标题品牌色和边缘反馈；`prefers-reduced-motion` 下关闭变换。
- 搜索框由 input 独占边框，建议面板独立浮层；键盘焦点环保持可见。
- 分类栏在窄屏横向滚动，不压缩成难以点击的按钮；点击目标保持至少 44px 高度。
- 推荐布局在 720px 以下变成主卡全宽、侧卡两列；普通网格为两列，450px 以下保持可读的两列缩略图。

## 保持不变

- 不修改路由、API、推荐排序、字段名、埋点和游戏运行时协议。
- 不替换 GameHub logo/wordmark，不改法律文案和用户可见中文文案。
- 不修改专门的深色游戏运行画面、截图灯箱和分享渠道色彩。

## 验收标准

- 首页截图在稳定数据态下不再呈现“灰色占位块 + 深色统计条 + 胶囊导航”的旧组合。
- 代表性首页、排行榜、标签、投稿、登录页使用同一套浅色内容平台语言。
- 53 个 GameHub 标准样式文件继续通过 token/raw-value/gradient 契约。
- 搜索框在默认、聚焦、建议面板状态下都只有一层输入边框。
- 桌面和响应式 CSS 检查无横向溢出，完整 GameHub 自检门禁通过。
