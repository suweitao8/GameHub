# GameHub 内容广场第二轮视觉重构

## 设计结论

上一轮已经解决了“彩色卡片”和搜索框叠框，但真实首页仍然过于空、过于像目录：15 个游戏卡片中没有真实封面时，页面主要由浅色占位块组成，推荐主卡只有一个大字，榜单和动态页也缺少内容平台的节奏。

本轮采用“B 站式内容组织、GameHub 游戏气质”的浅色内容广场：白色平台壳、冷白画布、蓝色单一品牌强调、缩略图优先、紧凑信息密度和明确的主次层级。参考的是内容平台的导航与浏览节奏，不复制 B 站品牌色、标识或页面文案。

## 视觉系统

- 画布保持冷白灰，内容表面保持白色，正文使用墨黑和中灰。
- 蓝色分成可读的行动蓝和明亮的媒体蓝；明亮蓝只用于品牌标识、选中线和少量状态。
- 搜索框使用浅灰字段底，始终只有 input 自身的一层边框；焦点只增加 input 的蓝色 focus ring。
- 普通卡片保持无白盒外框，封面占主要视觉面积；无封面时使用统一的海军蓝/冰蓝海报语言，不按游戏随机换颜色。
- 禁止产品壳层渐变、彩虹色和依赖图片平均色的运行时变色。

## 页面结构

1. 顶栏：品牌、社区入口、居中搜索、动态/收藏/历史/投稿入口，保持 56px 高度和清晰触控目标。
2. 频道栏：白色频道轨道，文字 Tab + 蓝色底部指示线；窄屏横向滚动。
3. 推荐区：12 列布局，左侧 6 列为有标题信息的推荐主视觉，右侧 6 列为两列精选卡，避免三列缩到不可读。
4. 普通分区：五列缩略图网格，卡片封面增加类别、序号/品牌小标和标题首字海报结构，标题、作者、播放/评论数据紧凑排列。
5. 榜单、标签、动态和作者页：沿用相同的画布、表面、分隔线、Tab 和状态 token，减少页面之间的视觉跳变。

## 交互与可访问性

- 卡片 hover 只做轻微上移、封面 1.045 倍放大和标题变蓝；减少动效时全部停止。
- 推荐轮播保留按钮、点位和 `aria-current`；焦点环可见。
- 搜索输入保留 `aria-controls`、`aria-expanded`、建议面板 `role=region` 和 Escape 关闭；搜索面板不改变输入框边界层数。
- 频道、排序、标签、榜单等可操作项保持最小 44px 触控高度。
- 不修改推荐服务、排序、路由、API、埋点、游戏运行时和数据字段。

## 验收标准

- 首页稳定态不再由“浅色占位块 + 空白大字”主导，主推荐和普通卡片具有统一的海报信息层次。
- 推荐侧栏在桌面为两列，标题和作者信息可读；窄屏为两列或单列，不产生横向溢出。
- 首页、榜单、标签、动态、作者页和搜索面板使用同一套蓝/墨/冷白语言。
- 搜索默认、聚焦、面板打开和 Escape 关闭状态都只有一层可见输入边框。
- 现有 GameHub 样式、客户端静态契约和完整自检门禁通过。
