# GameHub B 站式首页视觉重构设计规格

## 背景

当前游戏中心已经从旧的多彩皮肤切换到浅色内容平台方向，但首页仍然沿用“游戏卡片目录”的骨架：推荐区使用抽象占位海报，频道导航是一行文字标签，主推荐与普通卡片的媒体层级不够明显。参考图呈现的是 B 站首页式的内容发现体验：宽幅氛围 banner、密集频道 rail、图片优先的主推荐、缩略图上的播放信息，以及连续的内容流。

本次重构只调整前端展示层，不改变推荐算法、请求参数、路由行为、权限和游戏数据结构。

## 设计目标

1. 首屏一眼呈现“内容平台”，而不是后台或彩色游戏目录。
2. 通过图片、比例、密度和留白建立层级，颜色只保留 GameHub 青色品牌与少量热门粉色。
3. 有封面时真实封面优先；无封面时使用统一的 GameHub 场景图作为媒体兜底，不再让巨大首字母成为主视觉。
4. 首页、排行榜、创作者主页等发现类页面共享同一套浅色内容语言。
5. 搜索仍由一个输入框负责边框和焦点环，避免再次出现“两个搜索框叠加”。
6. 桌面端接近参考图的高密度，平板和手机端逐级降级为可横向浏览或两列内容，不产生横向溢出。

## 页面结构

### 顶部 shell

- 首页顶部 190px 左右的场景 banner 使用仓库已有的 `gamehub-header-banner-10x1.png`。
- 未滚动时 GameHub header 透明叠在 banner 上，文字和控件使用白色/半透明深色表面保证可读性。
- 页面滚动超过现有阈值后 header 自动切换为白底、细边框和轻阴影；不改变现有滚动状态逻辑。
- 搜索输入保留一个可见边框，由 input 自己承担 focus ring，搜索容器不再添加第二层边框。

### 频道 rail

- banner 之后放置白底频道导航，包含左侧“动态/热门”快捷入口、中间两行分类 chip，以及右侧社区/排行榜/攻略/活动快捷链接。
- chip 使用低对比度中性表面；active 只使用品牌青色底色或底部指示，不为每个分类分配颜色。
- 每个交互项保留至少 44px 的点击区域；窄屏允许 rail 水平滚动。

### 推荐区

- 主推荐采用 2:1 左侧 lead + 3 列 × 2 行 side rail 的媒体组合。
- lead 封面保持 16:9，标题、作者、播放量和评论量落在图片底部的单一深色 overlay 内；按钮、dots、键盘焦点仍然可用。
- side rail 使用垂直缩略图卡：16:9 图片、图片底部播放/评论信息、图片下方标题、作者和日期。
- 不使用渐变，不读取图片平均色，也不让占位首字母撑满封面。

### 普通内容流

- “我玩过的 / 最新发布 / 热门游戏”等区块保留现有数据来源和换一批动作，改为五列连续缩略图流。
- 内容卡不再套厚重白色外框；卡片只保留轻微圆角、图片和文字。
- 图片下方信息层级固定为：分类或状态、两行标题、播放/评论、作者/日期。

### 其他发现页面

- 排行榜保留 tab、分类筛选和排名信息，改成白色内容流：缩略图、标题、统计、热度值由细分隔线组织，不使用大面积白卡套白卡。
- 标签、动态和创作者主页沿用同一画布、墨色、边框和青色 active 语言；不引入新的彩色卡片体系。
- 游戏详情运行区、社区编辑器、上传流程不在本次视觉范围内，避免影响实际游玩和创作行为。

## 视觉令牌

- 画布：`#f6f7f8`，内容 surface：`#ffffff`。
- 文本：`#18191c` / `#61666d` / `#737a81`。
- 品牌：`#00aeec`，深色文本动作复用现有 `--game-brand-deep`。
- 热门强调：新增 `--game-hot: #fb7299`，仅用于热门入口或极少量状态，不用于逐卡染色。
- 媒体 overlay：新增 `--game-media-overlay: rgb(24 25 28 / 72%)`，使用纯色透明层，不使用渐变。
- 内容宽度：桌面端扩大到约 1800px，同时通过页面 gutter 保持两侧呼吸空间。

## 交互和无障碍

- 保持现有 RouterLink、query params、推荐轮播自动播放、左右按钮、dots 和触摸滑动。
- active 分类有文字/颜色以外的结构差异，并维持键盘 focus-visible。
- 图片 alt 保留游戏标题；占位装饰图使用空 alt/aria-hidden，不能重复读标题。
- `prefers-reduced-motion` 下关闭卡片抬升、图片缩放和轮播装饰动画。
- 搜索面板的历史、建议、Escape 关闭、loading 状态不变。

## 不做的事情

- 不重写推荐算法或推荐接口，不改变排序权重。
- 不新增 npm 依赖，不生成一套多彩封面资源。
- 不把旧 `mydrama` 项目代码直接复制到 GameHub；只参考其浅色内容平台的密度和层级。
- 不以静态截图替代真实浏览器验收。

## 验收标准

- `/games` 桌面首屏具备 banner、两行频道 rail、主推荐 + 3 列 side rail。
- 30 个当前无封面游戏仍呈现统一的媒体缩略图，而不是巨大字母/纯色块。
- `/games/rankings`、`/games/tags`、`/games/activity`、`/games/author/:id` 使用统一浅色内容语言。
- 搜索输入只有一层可见边框，聚焦时只有 input 自己的 focus ring。
- 1280px、1440px 和手机宽度无横向溢出；键盘、触摸轮播、搜索 Escape 均可用。
- 项目自检、客户端构建、相关 lint 和真实 9000 页面验收均通过。
