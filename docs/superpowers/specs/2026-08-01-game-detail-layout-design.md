# GameHub 游戏详情页布局优化设计

## 目标

修复游戏详情页中由 SVG 资源污染、容器比例、间距、图标基线和响应式规则不一致造成的视觉错位，让标题区、游戏区域、讨论群、操作栏和评论区形成稳定的桌面与窄屏布局。

## 设计决定

- 页面内容使用 `calc(100% - 48px)` 并限制最大宽度 `1280px`，避免大屏两侧出现过宽留白。
- 标题区和游戏区统一使用 4:1 主区/侧栏网格，列间距统一为 16px。
- 游戏区域使用稳定的响应式高度，桌面端控制在 `clamp(360px, 44vw, 680px)`，窄屏端降为单列并使用 320px 至 560px 的高度。
- 游戏详情页统一 `box-sizing: border-box`，标题、开发者、播放器按钮和讨论群输入区使用明确的 16/20/32/48px 尺寸基线。
- 标题统计保留图标和数字，去掉重复的“游玩/评论”文字；点赞、投币、收藏、分享操作采用图标与紧邻文本的单行排列。
- Tabler SVG 资源必须是纯 SVG 文本，不能含有 shell 命令输出；静态自测直接检查资源根节点和污染文本。
- 评论和讨论群业务逻辑不变，只收敛卡片边界、内边距、头像、气泡和输入控件的对齐。

## 不在本次范围

- 不修改游戏上传、评论/讨论群 API、数据库模型或路由。
- 不覆盖主工作区已有的 header 未提交改动。

## 验收标准

1. `/games/:uuid` 桌面端标题区、主游戏区和讨论群边界对齐，图标不带命令输出文本。
2. 详情页统计和互动操作均为图标/文字同一基线，不出现多余的第二行标签或控制条撑高。
3. 900px 以下布局切换为单列，600px 以下仍无水平溢出，讨论群输入区可用。
4. GameHub 静态契约、客户端构建、lint 和固定 9000 端口的 live SPA 检查全部通过。
