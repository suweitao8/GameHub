# GameHub Logo 蓝品牌视觉重构

日期：2026-08-31

## Design Read

本设计稿基于当前 `develop` 的 Logo、GameHub 设计令牌、首页真实页面和既有样式统一工作成果。当前 Logo 使用 `#00aeec`，但页面框架同时大量使用灰紫中性色、粉色主行动色和多彩内容色，品牌识别不够集中。本次重构将 Logo 蓝提升为全站品牌主轴，同时保留游戏封面和内容本身的丰富色彩。

## 背景

GameHub 的主要使用者是浏览、游玩和投稿的玩家与创作者。页面需要轻快、有游戏感，但不能让导航、搜索、按钮、卡片和表单各自使用不同的视觉语言。现有 `game-community.tokens.scss` 已提供统一令牌入口，本次以原生 SCSS 令牌和现有组件结构完成重构，不新增依赖或改变业务接口。

## 目标

- 让 `#00aeec` 成为导航、搜索焦点、主要按钮、选中态和关键链接的共同品牌颜色。
- 用冰蓝画布、白色内容层和深蓝墨色文字建立清晰层级，降低当前灰紫和粉色对品牌的干扰。
- 将粉色从主行动色降为少量热门、提醒和状态强调色；游戏封面继续保留内容色。
- 统一首页、游戏详情/游玩、作者、社区、账号、登录注册、上传工作台和反馈控件的视觉契约。
- 保持现有路由、接口、权限、游戏 iframe、分享平台品牌色、封面内容和交互行为不变。

## 视觉系统

### 色彩令牌

| 令牌 | 目标值 | 用途 |
| --- | --- | --- |
| `--game-page-bg` | `#f1fbfe` | 页面主画布 |
| `--game-surface` | `#ffffff` | 卡片、面板、弹层 |
| `--game-surface-alt` | `#e7f6fb` | 次级背景、输入框、浅色分区 |
| `--game-surface-active` | `#dff2f8` | hover、选中和轻量强调 |
| `--game-text-primary` | `#0c2d3a` | 标题和主要文字 |
| `--game-text-secondary` | `#496976` | 正文和辅助说明 |
| `--game-text-hint` | `#6e8792` | placeholder、弱提示 |
| `--game-border` | `#d0e6ed` | 默认边框和分隔线 |
| `--game-border-strong` | `#adced8` | 强边框、输入 focus 外层 |
| `--game-brand` | `#00aeec` | 主行动、链接、焦点 |
| `--game-brand-hover` | `#009dd5` | hover/pressed |
| `--game-brand-deep` | `#007aa3` | 深色链接、选中文字 |
| `--game-brand-soft` | `#e5f7fc` | 品牌浅底 |
| `--game-brand-border` | `#b3e4f1` | 品牌边框 |
| `--game-brand-contrast` | `#06222d` | 品牌底上的文字/图标 |
| `--game-cover-fallback` | `#00627f` | 无封面内容的品牌兜底 |

危险、警告、成功等语义色继续由现有语义令牌管理，不把品牌蓝用于表达错误或风险。粉色仅用于热门、提醒等明确的状态强调。

### 排版与形状

- 标题、导航和按钮沿用当前字体栈与既有字号层级，以深蓝墨色增强可读性。
- 页面主容器使用中等圆角；卡片、输入框和按钮使用一致的圆角和边框令牌，避免每个页面出现独立的灰色边框。
- 阴影保持轻量，主要使用蓝灰色透明阴影，不使用大面积彩色光晕。
- 主要行动使用实心 Logo 蓝，次要行动使用白色或冰蓝底；仅链接和 focus 使用品牌蓝描边/文字。

## 页面应用

- **全局壳层**：页背景、页脚、顶部导航和搜索统一使用冰蓝/白色层级；活跃导航、搜索 focus 和主要操作沿用品牌蓝。
- **首页与发现**：频道、筛选、标题行、推荐卡片和空状态使用品牌浅底与白色面板；内容封面保留原始多彩视觉，但外框、信息层和状态控件归一到蓝色系统。
- **游戏详情与游玩**：详情信息、作者卡片、相关游戏、社区入口和操作按钮使用同一套表面/边框/品牌令牌；运行时 iframe 不改内部渲染和第三方品牌色。
- **社区、作者和工作台**：评论、讨论、投稿、创建和管理操作用蓝色表达主要行动，状态反馈仍使用语义色。
- **账号与认证**：登录、注册、重置密码、设置和账号页面共享输入、按钮、卡片和错误状态契约。
- **弹层与反馈**：下拉、模态、Toast 和表单 focus 保持白色/冰蓝层级，确保遮罩、键盘 focus 和关闭操作清楚可见。

## 交互与无障碍

- 普通文字与背景保持至少 4.5:1 对比度，大号文字和 UI 控件至少 3:1。
- 链接、按钮、输入框、导航和卡片必须有明确的 hover、focus-visible、disabled、loading、error 和 empty 状态；focus 不依赖颜色 alone。
- 搜索框保持单层边框/焦点环，placeholder 不与输入文字或图标重叠。
- 响应式布局覆盖桌面和 375px 窄屏；可点击控件的触控区域不小于 44px，内容不产生横向溢出。
- 尊重 `prefers-reduced-motion`，不为颜色重构引入新的持续动画。

## 范围边界

本次只调整前端视觉层、共享令牌、必要的静态样式契约和验证脚本。不会修改 API、数据库、路由、权限、游戏运行时 iframe、第三方分享平台颜色、上传文件处理或新增依赖。不会直接编辑生成的 dist、node_modules 或用户本地配置。

## 验收

1. 首页、详情、作者、社区、账号、认证和上传工作台的页面框架均以 Logo 蓝为主行动色，且不再由粉色承担默认主 CTA。
2. 设计令牌、全局桥接和主要页面样式通过项目静态契约检查；服务端构建、全仓 lint 和 GameHub 自检门禁通过。
3. 使用 ZCode 内置浏览器验证桌面与 375px 窄屏：导航、搜索、筛选、按钮、弹层、表单 focus、空/错误状态可见且无横向溢出。
4. 运行时游戏 iframe、封面内容、路由和接口行为没有被视觉改动破坏。
