# /md — GameHub 规则文件维护

用于用户要求迁移、审计、优化或记录项目规则时。`AGENTS.md` 是唯一的项目级权威规则源；`client/AGENTS.md` 只负责客户端目录的局部补充。

## 强制流程

1. 用 UTF-8 完整读取受影响的 `AGENTS.md`，保留无关的既有规则。
2. 手术式修改，只添加项目特有、可执行且不会过时的内容。
3. 立即审查命令/工作流、架构准确性、陷阱覆盖、简洁性、时效性和可执行性。
4. 发现重复、矛盾、过时命令或模糊描述时，当场优化后再提交。
5. 用 `git diff --check` 检查文档质量，并确认状态只包含预期规则文件。

## 不应写入的内容

- 其他项目的业务架构、路径、端口或专属工具。
- 无法在当前仓库验证的命令。
- 一次性故障的长篇过程记录。
- 与 `client/AGENTS.md` 重复的 Angular 细节。
